Engineering Architecture & Design Choices

This agentic system is architected as a self-contained autonomous quality control loop rather than a single prompt.

Architectural Component Alternative Considered Why Chosen (Engineering Trade-Off)
Two-Tier Evaluator (Linter + LLM Judge) Single monolithic LLM prompt Static regex filters catch 80% of ungrounded jargon and sentence length violations in <5ms, drastically cutting LLM token costs and latency.
Strict Hard Pass/Fail Rubric 1-to-10 Likert numerical score In educational publishing, zero partial credit is required. An 8/10 lesson with a single hallucinated premise damages beginner comprehension.
Guaranteed Termination (Max Retries = 2) Open-ended reflection loops Prevents runaway API spend and infinite loop deadlocks while giving the generator 2 attempts to incorporate feedback.
Persistent Institutional Memory Ephemeral in-memory cache Persists failure signatures to disk (`data/institutional_memory.json`) so the system learns from past rejections across server restarts.
